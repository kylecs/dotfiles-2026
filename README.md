# 2026 dotfiles

**Theme:** Gruvbox dark, with an acario-light port to switch to
**Font:** Iosevka Term Nerd Font

## Terminal: kitty
Just the window. No splits, tabs or key maps that would intercept keys, so
everything reaches Neovim.

## Editor and multiplexer: Neovim
Neovim is the top level now: it does the splits, tabs and terminals that tmux
used to, with a leader-key setup modelled on my Emacs config. See
[nvim/README.md](nvim/README.md).
